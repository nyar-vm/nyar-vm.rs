# python

Python frontend for the `nyar-language` analysis framework.

## Scope

- **Format**: `SourceFormatter` plugin (`python` / `py`).
- **Lint**: first-party hygiene rules (no external ruff/black/flake8).
- **Module**: concrete `PythonModule` with language id `python`.

Not a `nyar-vm` compile target. Product CLI: `panda`.
