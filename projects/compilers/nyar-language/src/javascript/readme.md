# javascript

JavaScript / TypeScript frontend for the `nyar-language` analysis framework.

## Scope

- **Format**: `SourceFormatter` plugin (`js` / `ts` / `json` aliases).
- **Lint**: first-party hygiene rules (no external eslint/biome).
- **Module**: concrete `JavascriptModule` with language id `javascript`.

Not a `nyar-vm` compile target. Product CLI: `noodle`.
