# 对象级动态技术 (Object-level Dynamic Technology)

Nyar VM 的对象级动态技术赋予了语言高度的灵活性，支持动态类型、动态对象模型以及运行时的代码求值。

## 1. 动态对象 (Dynamic Objects)

除了传统的基于类的对象（Class-based Objects），Nyar 还支持完全动态的对象模型。

- **动态创建**：通过 `NewDynObject` 指令，可以创建一个没有任何预定义 Schema 的空对象。
- **自由属性**：动态对象在内部使用高效的哈希表存储成员。你可以随时向对象添加、修改或删除属性和方法。
- **鸭子类型 (Duck Typing)**：虚拟机在处理 `InvokeMethod` 指令时，如果接收者是动态对象，会自动在其成员列表中查找匹配的方法名称，从而实现灵活的多态性。

## 2. 深入多态：Trait 与 Abstract Class

Nyar VM 通过底层的指令集支持复杂的面向对象和函数式多态特性：

- **Witness Tables (见证表)**：这是实现 Trait 多态的核心。通过 `GetWitnessTable` 指令，VM 可以为特定类生成满足特定 Trait 的方法映射表。这类似于 C++ 的虚函数表（vtable），但在运行时更加动态。
- **WitnessMethod 调用**：通过 `WitnessMethod` 指令，VM 可以从见证表中提取具体的闭包并执行。这种方式实现了真正的接口多态，允许代码编写时不依赖于具体实现类。
- **Existential Types (存在类型)**：指令集预留了 `OpenExistential` 和 `CloseExistential`，用于处理封装了具体类型信息的 Trait 对象。这支持了类似于 Rust `dyn Trait` 的行为，使得不同类型但实现相同接口的对象可以存储在同一个集合中。
- **Abstract Class (抽象类)**：通过 `InstanceOf`, `CheckCast` 和 `Cast` 指令，VM 支持基于继承层次结构的类型检查和强制转换。这为抽象基类和类层次结构的多态性提供了基础。

## 3. 动态分发与内置操作

Nyar VM 的指令集内置了对动态行为的支持：

- **多态调用**：`InvokeMethod` 不仅仅用于类成员函数。它会根据 `Value` 的运行时标签（ValueTag）自动选择执行路径。
- **内置方法映射**：对于基础类型（如 `Int`, `String`, `Array`），VM 预定义了一系列标准方法（如 `add`, `len`, `push`）。这使得开发者可以用统一的语法操作不同类型的数据。
- **集合动态性**：数组（Array）和列表（List）支持动态扩容、切片以及元素类型的混合存储。

## 4. 运行时求值 (Eval)

`Eval` 指令是 Nyar 动态性的核心体现之一：

- **代码即数据**：通过 `Eval`，程序可以在运行时接收字节码片段并立即执行。
- **元编程支持**：这为宏展开、动态脚本执行以及解释器嵌套提供了基础。

## 5. 类型系统的动态边界

虽然 Nyar 支持强类型检查，但其底层 `Value` 结构允许在动态边界上进行灵活切换：

- **ValueTag**：每个值都携带一个类型标签，支持运行时反射（`TypeOf`）和类型检查（`InstanceOf`）。
- **安全转型**：提供 `Cast` 和 `CheckCast` 指令，在保证安全的前提下在动态对象与结构化对象之间进行转换。

通过这些对象级的动态技术，Nyar 能够平衡静态类型的安全性和动态语言的开发效率，满足从快速原型开发到大规模系统构建的不同需求。
